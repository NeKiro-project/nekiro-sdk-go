# NeKiro Go SDK RepoWiki

This is the bilingual reading surface for the public Go Agent and application
SDKs. The repository source files remain canonical; the MkDocs tree is built
from those documents in CI.

## Start here

- [Source documentation](source-docs/index.md) — overview, Agent SDK, and Workspace client pages.
- [GitHub repository](https://github.com/NeKiro-project/nekiro-sdk-go) — source, issues, and releases.
- [Core RepoWiki](https://nekiro-project.github.io/NeKiro/) — platform contracts and architecture.

The SDK never imports Core service internals, discovers endpoints, retries,
selects alternate components, or provides an Agent Runtime.
